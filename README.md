# pulse-gen — 多模式脉冲信号发生器

基于 STM32F103RCT6 的手持式多模式脉冲发生器：0.96 寸 OLED 显示 + 三键遥控器式交互，支持 **PWM 连续输出 / 双脉冲单次输出 / 清零+单脉冲** 三种模式，参数掉电保存。

**硬件平台**：元杞科技 STM32F103RCT6 核心板（72MHz，淘宝有售），核心板自带按键与 LED，另接一块 0.96 寸 OLED（SSD1306/SSD1315，软件 SPI 驱动）。

---

## 功能总览

| 模式 | 功能 | 输出通道 |
|---|---|---|
| **双脉冲** | 按触发键输出一次"高-低-高-低"的双脉冲序列（P1/间隔/P2 可设），运行中再触发自动丢弃 | 固定 6 路齐发 |
| **PWM** | 6 路连续 PWM，每路独立占空比/相位，频率可设；支持 T3/T4 主从同步 | 6 路（可勾选） |
| **清零+单脉冲** | 周期性清零脉冲流 + 触发后插入单脉冲（罗氏线圈清零类应用） | C1=清零，C4/C5/C6=单脉冲 |

### 各模式详解

**双脉冲（Dual）**
- 参数：脉冲1宽度 / 两脉冲间隔 / 脉冲2宽度（µs，分辨率 1µs）
- 时序：上电起预留 10µs 后输出（隔离软件建立时间），空闲低电平，序列结束保持低
- 触发一次输出一次；序列运行中触发被丢弃
- T3 主/T4 从触发同步启动（同沿偏差 ≈ 几十 ns），无 DMA 竞态

**PWM（连续脉冲）**
- 参数：每路 频率（Hz）/ 占空比（**0.01% 粒度**）/ 相位（0~99%）
- 通道子页可勾选 6 路中的任意组合；Sync 选项使 T4 跟随 T3 共用一个频率（T3 主门控 T4）
- PWM 使能开关控制整链路输出
- 实现机制：OC Toggle + DMA 循环写 CCR，任意相位/占空比组合

**清零+单脉冲（Clear+Single）**
- 参数：清零频率 / 清零脉宽 / 清零-单脉冲间隔 / 单脉冲脉宽
- 工作方式：ClrEn=ON 后 C1 持续输出周期性清零脉冲流；按 Trig 武装一次，在**下一个清零脉冲结束 + 间隔 µs** 处精确输出一个单脉冲（三路齐出），完成后自动卸装
- 触发采用 T3 CC3 比较中断软件启动 T4（带 1.5µs 中断开销补偿），落点精度亚微秒级
- 进模式默认 ClrEn=OFF，切出模式自动停输出并复位 OFF

### 参数掉电保存
所有参数（含模式、通道勾选、频率/占空比/脉宽）实时保存在内部 FLASH 最后一页（带 magic+尺寸+校验和三重防护），断电重启自动恢复。使能开关（PWMEn/ClrEn）不持久化——上电永远不会自动开输出。

## 硬件接口

### 输出引脚（对应 UI 编号 C1~C6）

| UI 编号 | 定时器通道 | 引脚 |
|---|---|---|
| C1 | TIM3_CH1 | PA6 |
| C2 | TIM3_CH3 | PB0 |
| C3 | TIM3_CH4 | PB1 |
| C4 | TIM4_CH1 | PB6 |
| C5 | TIM4_CH2 | PB7 |
| C6 | TIM4_CH3 | PB8 |

> TIM3_CH2(PA7)、TIM4_CH4(PB9) 板上不可用。
> 定时器分工：TIM3 主 / TIM4 从（ITR2 相连），清零+单脉冲模式下 TRGO=OC3REF。

### 其他外设

| 外设 | 引脚 | 说明 |
|---|---|---|
| OLED SDIN/SCLK/RST/DC/CS | PC0 / PC13 / PC1 / PC2 / PC3 | 软件 SPI |
| K_UP | PA0 | 上键（高有效） |
| K1 | PA15 | 确认键（低有效） |
| K0 | PC5 | 下键（低有效） |
| LED0/LED1 | 板载 | 心跳/触发指示 |
| 串口 USART1 | 板载 | 115200-8-N-1，每秒状态打印 |

## 操作手册

### 按键定义（遥控器手感）

| 按键 | 短按 | 长按(≥1s) |
|---|---|---|
| **K_UP** | 光标上移 / 编辑时数值**减** | 编辑时按住连发加速（越久倍率越大） |
| **K1** | 确认（进入/切换/保存） | 子页返回上级 / 编辑取消 |
| **K0** | 光标下移 / 编辑时数值**加** | 同上（连发加速） |

编辑页数值步进：短按 ±1，按住 2s 起 ×10，5s 起 ×100（自适应加速）。

### 页面结构

```
主页（模式行可上下换模式，Back 到顶）
 ├─ 模式选择：光标移到 Mode 行，上/下切换模式，短按 K1 锁定，长按 K1 取消
 ├─ PWM 模式行：PWMEn[OFF/ON] → CH-Sel(通道子页) → Freq T1/T2 → 各路 Duty/Phase → Trig[GO]
 ├─ 双脉冲行：P1 → Gap → P2 → Trig[GO]
 └─ 清零+单脉冲行：ClrEn[OFF/ON] → Trig[GO] → Freq → ClrW → ClrI → Pulse
通道子页：Back(置顶) → 6 路勾选[√] → Sync[√]
编辑子页：数值 + 取值范围显示，K1 短按保存 / 长按取消
```

### 典型操作流程

- **改参数**：光标移到参数行 → K1 进入编辑 → 上/下调值（按住加速）→ K1 短按保存退出；保存时自动校验，非法值（如超出周期、超出分辨率极限）直接拒绝并回滚，参数保持原值
- **PWM 输出**：PWM 模式 → 通道子页勾选需要的路 → 设频率/占空比/相位 → PWMEn 翻到 ON；关闭则翻回 OFF 或直接切走模式（自动停）
- **双脉冲**：设 P1/Gap/P2 → 按 Trig 一次输出一次
- **清零+单脉冲**：设四参数 → ClrEn 翻 ON（清零流开始）→ 每按一次 Trig 在下一个周期插入一个单脉冲
- **切模式**：主页第一行光标处上/下切换；输出中切走会立即停输出

---


### 串口诊断（115200）
每秒打印状态行：模式/使能/触发计数/频率/各路占空比相位；关键事件（触发、模式切换、PWM 启停、参数加载）有独立消息。上电打印 `param load OK(flash)` 表示参数从 FLASH 恢复，`DEFAULT` 表示首次使用默认值。

## 软件架构

```
App/
 ├─ pulse.c/h    参数与行模型: 三模式参数集、编辑引擎(步进/校验/回滚)、FLASH 保存
 ├─ display.c/h  OLED 显示封装: 主页/通道子页/编辑子页, 整行刷新防残影
 ├─ key.c/h      三键扫描: 去抖20ms/长按1s/自适应连发
 ├─ pwm.c/h      硬件核心: TIM3主/TIM4从, 三种输出机制的统一启动/停止/校验
 └─ stmflash.c/h 内部FLASH读写(整页缓存+按需擦除, 移植自例程19)
Core/Src/main.c  UI 四态状态机 + 主循环调度(1秒非阻塞任务)
```

### 实现要点（踩坑记录，供同类项目参考）
- PWM 任意相位/占空比：OC Toggle + **DMA 循环写 CCR**，比较点数组必须**降序**排布 + 预装最小值，否则极性错位
- F103 HAL 坑 1：`TIM_DMA_ID_CCx` 是数组索引（0 被 UPDATE 占用）不是 DIER 掩码，`TIM_DMA_CCx << dma_id` 会整体错位一格
- F103 HAL 坑 2：`HAL_DMA_Start` **不应用** `Init.Mode`（仅 `HAL_DMA_Init` 写寄存器），改 Mode 后不重新 Init 是无效操作
- F103 HAL 坑 3：`TIM_Base_SetConfig` 保留 CR1 其他位——OPM 位残留会让连续模式只跑一个周期
- 单脉冲精确触发：从机 Trigger 模式对 TRGO=OC3REF 电平型触发源边沿检测不可靠，改用**主定时器 CC 中断软件启动从机** + 固定开销补偿
- OPM 预装 CCR=0 会形成"持续匹配"立即置位比较标志，前置量必须 ≥1 tick
